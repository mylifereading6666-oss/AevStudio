サイトの使い方・全機能ガイド

初めて使うときの基本操作から、プロジェクト作成、複数ページ編集、コード確認、保存・書き出し、学習機能までを項目別に説明します。各項目を押すと説明を開閉できます。

プロジェクトを始める →学習コンテンツを見る
基本操作アカウントプロジェクト制作エディタ保存・書き出し学習・コード安全・注意事項困ったとき

1. 基本操作・画面の見方

AevStudioの共通画面と、最初に覚えておく操作です。

1-1. ロゴ・ホームへ戻る

画面左上のAevStudioロゴを押すとホームへ戻ります。作業中の内容がある場合は、移動前に保存状態を確認してください。

1-2. 三本線メニュー

画面上部の「メニュー」を押すとナビゲーションが開きます。項目は「制作」「学習・資料」「アカウント」に分類されています。分類名を押すと中のリンクを折り畳めます。背景部分、閉じるボタン、Escキーでも閉じられます。

スマートフォンではメニュー内をスクロールして目的の項目を探してください。

1-3. ログイン状態の表示

未ログイン時は「ゲストモード」と表示され、ログイン／登録ボタンが表示されます。ログイン後はアカウントのメールアドレスなどが表示され、オンライン状態の表示に切り替わります。

1-4. スマートフォン・タブレット・PCでの利用

画面幅に合わせてレイアウトが変わります。エディタではプレビュー幅を「自動（画面幅）」「PC」「タブレット」「スマホ」から選び、各サイズで表示を確認できます。

画面サイズを切り替えた後は、文字の折り返し、画像のはみ出し、ボタンの押しやすさも確認してください。

2. アカウント・ログイン

ログインすると、アカウント単位でプロジェクトをクラウド管理できます。

2-1. 新規登録
  1. 画面上部の「ログイン / 登録」を押します。
  2. ログイン画面内の「アカウントを新規登録」を選びます。
  3. メールアドレスとパスワードを入力して登録します。
  4. 確認メールが届いた場合は、メール内の案内に従って確認を完了します。

登録確認の方法はSupabase側の認証設定によって異なる場合があります。

2-2. ログイン

「ログイン / 登録」からメールアドレスとパスワードを入力し、「ログイン」を押します。ログイン状態はブラウザーに保持され、次回アクセス時にもセッションが有効であれば引き継がれます。

2-3. ログアウト

ログイン中にアカウント操作ボタンを押すとログアウトできます。ログアウト後はゲストモードになります。クラウドに保存したプロジェクトはアカウントに残りますが、再び開くには同じアカウントでログインしてください。

2-4. アカウント管理ページ

メニューの「アカウント管理」から開きます。ログイン情報欄ではログイン状態、メールアドレス、ユーザーID、アカウント作成日を確認できます。

アカウント管理を開く →

2-5. パスワード変更
  1. アカウント管理ページを開き、ログインしていることを確認します。
  2. 「新しいパスワード」と「新しいパスワード（確認）」に同じ内容を入力します。
  3. 「パスワードを変更」を押します。

入力欄は6文字以上が条件です。確認欄と一致しない場合や未ログインの場合は変更できません。

3. プロジェクトの作成・管理

Webサイトは「プロジェクト」として管理します。最初にプロジェクト名・用途・ページ数を決めます。

3-1. プロジェクト一覧

メニューの「プロジェクト」から一覧を開きます。新規作成、保存済みプロジェクトの確認、制作の再開を行う場所です。

プロジェクト一覧を開く →

3-2. 新しいプロジェクト
  1. 「新しいプロジェクト」を押します。
  2. 「新しいプロジェクト」を選びます。
  3. 用途に合うテンプレートを選びます。
  4. プロジェクト名を入力します。
  5. 必要なページ数を1〜10ページから選びます。
  6. 「プロジェクトを作成」を押します。

作成後は制作エディタで内容を編集できます。

3-3. プロジェクトの種類・テンプレート
  • 空白のWebサイト：決まった構成を使わず自由に作る土台。
  • ポートフォリオ：プロフィール、作品、制作実績の紹介。
  • サービス紹介・LP：サービスや商品の特徴を伝えるページ。
  • ブログ・メディア：記事やお知らせを掲載する構成。
  • オンラインショップ：商品を紹介するサイトの土台。決済機能そのものが自動で有効になるわけではありません。
  • レストラン・カフェ：店舗情報やメニューの紹介。
  • イベント・告知：開催情報、プログラム、会場案内。
  • 写真・ギャラリー：写真や作品の展示。
  • ゲーム・コミュニティ：ゲーム関連情報やコミュニティ案内。
  • 制作会社・ビジネス：事業内容、サービス、実績の紹介。

テンプレートは初期構成です。実際の文章・画像・機能は用途に合わせて編集してください。

3-4. ページ数の選び方

作成時に1〜10ページを選択します。1ページのサイトなら1、ホーム・紹介・問い合わせなどを分ける場合は必要な数を選びます。ページ数はサイト全体のページ構成の初期値です。

3-5. 続きから制作
  1. プロジェクト開始画面で「続きから」を選びます。
  2. 端末内に保存されたプロジェクトと、ログイン中ならクラウドのプロジェクトが一覧に表示されます。
  3. 再開したいプロジェクトを選択します。
  4. 「選択したプロジェクトを開く」を押します。

クラウドのプロジェクトを開く場合は、保存時と同じアカウントでログインしてください。

3-6. プロジェクトを切り替える・新規作成する

制作エディタ左側の「マイプロジェクト」から編集対象を切り替えられます。「＋ 新規」から別のプロジェクトを作成できます。切り替え前に保存状態を確認してください。

4. 制作エディタの使い方

制作エディタは、ビジュアル編集とHTML・CSS・JavaScript編集を切り替えながらWebサイトを作る画面です。

4-1. エディタ画面の構成
  • 左側：マイプロジェクト一覧と新規作成。
  • 上部：プロジェクト名、保存状態、保存、ZIP書き出し。
  • ページ構成：ページの選択と追加。
  • 編集タブ：ビジュアル、HTML、CSS、JavaScript。
  • プレビュー：編集中のページの表示確認。

制作エディタを開く →

4-2. プロジェクト名

エディタ上部の入力欄で名前を変更します。プロジェクト一覧で識別しやすい名前を付けてください。

4-3. ページ構成・ページを追加

「ページ構成」にはプロジェクト内のページが並びます。編集したいページを選択すると、そのページの内容が編集対象になります。「＋ ページを追加」でページを増やせます。

複数ページのサイトでは、各ページに分かりやすいタイトルを設定し、ページ間の移動リンクも用意してください。

4-4. ビジュアル編集

コードを直接書かずに基本情報を編集するモードです。

  • ページタイトル：ページの見出し・タイトルに使う文字。
  • 紹介文：ページの内容を説明する文章。
  • アクセントカラー：ボタンや強調箇所などの基調色。
  • テンプレート：空白、ポートフォリオ、サービス・LP、ブログ、ショップ、店舗、イベント、写真、ゲーム、ビジネスなどの構成を選びます。

テンプレートを切り替えるとページ構成が変更されるため、必要な文章や内容を確認し直してください。

4-5. 画像・写真を追加
  1. 画像URLを使う場合は「画像URL」に画像のアドレスを入力します。
  2. 必要に応じて「画像の説明」に画像の内容を入力します。
  3. 「URL画像を追加」を押します。
  4. 端末内の画像を使う場合は「端末から画像を選択」を押し、画像ファイルを選びます。

追加した画像はページ末尾のギャラリーに追加されます。JPEG・PNG・WebPに対応し、アップロード画像は自動で軽量化されます。

画像の利用権限を確認してください。個人情報や他人の写真を、許可なく公開しないでください。
4-6. HTML編集

「HTML」タブではページの構造を編集します。見出し、段落、リンク、ボタン、画像、フォームなどの要素を記述します。HTML内のIDやクラス名をJavaScript・CSS側と一致させてください。

4-7. CSS編集

「CSS」タブでは色、文字サイズ、余白、配置、枠線、レスポンシブ表示などを設定します。HTMLのクラス名やIDをセレクターとして指定します。

4-8. JavaScript編集

「JavaScript」タブではボタン操作、メニュー開閉、入力チェックなどの動作を追加します。対象となるHTML要素が存在しているか、イベントが重複登録されていないか確認してください。

4-9. コード診断・エラー表示

コード編集時は診断欄を確認します。エラーや注意が表示された場合は、対象コードの構文、閉じタグ、括弧、ID・クラス名、要素の存在を確認してください。診断で問題が見つからなくても、実際の動作が正しいとは限らないためプレビューで確認します。

4-10. ライブプレビュー

編集内容をプレビュー領域で確認できます。「更新」で表示を再読み込みします。画面幅の選択からPC・タブレット・スマートフォン相当の表示を確認してください。

4-11. 閲覧モード

プレビュー内のメニュー、ボタン、リンクなどを通常の利用者と同じように操作するモードです。ページ移動や開閉など、サイトとしての操作感を確認します。

4-12. コード確認モード

プレビュー内の要素を確認し、どの部分を編集するか調べるためのモードです。通常操作を試すときは「閲覧モード」に戻してください。

4-13. プレビューで別ページへ移動するとき

プレビューは安全のため隔離された領域で表示されます。外側のエディタとプレビュー内ページではブラウザーの制限が異なります。プレビュー内のリンク動作が外部ブラウザーと完全に同じとは限らないため、書き出したファイルでも確認してください。

5. 保存・同期・書き出し

制作内容を失わないように、保存状態を確認し、必要に応じてファイルを書き出します。

5-1. 自動保存と保存状態

エディタは変更内容を端末側に保存し、ログイン中はアカウントのクラウド同期にも対応しています。画面上部の保存状態を確認してください。ネットワークが不安定な場合は、同期が完了するまで待ってからページを閉じてください。

重要な変更の直後は「保存」も押し、保存完了表示を確認することをおすすめします。

5-2. 手動保存

上部の「保存」を押すと現在のプロジェクトを保存します。保存状態が更新されたことを確認してください。

5-3. ゲスト保存とクラウド保存の違い
  • ゲスト：利用中の端末・ブラウザーに保存されます。別端末や別ブラウザーへ自動では引き継がれません。
  • ログイン中：端末内の保存に加え、同じアカウントのクラウドデータと同期します。

端末を変更する予定がある場合は、ログインして同期が完了していることを確認してください。

5-4. ZIP書き出し

「ZIP書き出し」を押すと、Webサイトのファイル一式をZIP形式で保存します。現在の書き出し構成には index.html、style.css、script.js が含まれます。ダウンロード後に解凍し、内容を確認してからGitHub Pagesなどのホスティング先へ配置します。

ZIPを書き出しただけではインターネット上に公開されません。公開先へのアップロード・設定は別途必要です。
5-5. HTML保存

「HTML保存」は現在のページのHTMLをファイルとして保存するための機能です。CSS・JavaScriptも含めた一式が必要な場合はZIP書き出しを利用してください。

5-6. 書き出し後の確認
  1. ZIPを解凍します。
  2. ファイル構成と画像などの参照先を確認します。
  3. index.htmlをブラウザーで開き、表示と操作を確認します。
  4. 公開先へ配置した後、PCとスマートフォンの両方で確認します。

6. 学習・テンプレート・応用コード

制作の基礎を学び、必要な機能のサンプルコードを探すための機能です。

6-1. Web制作を学ぶ

「Web制作を学ぶ」では、HTML・CSS・JavaScriptの基礎、複数ページ構成、アカウント画面、三本線メニュー、よく使われる機能の教材などを確認できます。大きな教材項目と個別カードは折り畳んで、必要な説明だけを表示できます。

Web制作を学ぶを開く →

6-2. HTML・CSS・JavaScriptの基礎
  • HTML：ページの骨組み。見出し、文章、画像、リンクなど。
  • CSS：見た目。色、配置、余白、文字、画面幅への対応。
  • JavaScript：動作。クリック、入力、表示切り替え、データ処理。
6-3. 複数ページのWebサイト教材

ページごとに役割を分け、ページ一覧からページを追加し、リンクで相互に移動できるようにします。例：ホーム、サービス紹介、問い合わせの3ページ構成です。

実際のWebサイトで使う機能を、説明・用途・サンプルコード・注意点と合わせて学ぶ項目です。教材内のコード検索リンクを押すと、応用コード一覧へ移動し、関連する検索語が自動入力されます。

HTML・CSS・JavaScriptのサンプルを検索し、用途別に探せます。コード名の一部、用途、関連語で検索し、分類ボタンで絞り込めます。

7. 安全に利用するための注意事項

Webサイトの見た目だけでなく、データやアカウントを守る設定も必要です。

7-1. パスワード・APIキーをコードに書かない

パスワード、秘密鍵、Supabaseのservice_roleキーなどをHTML・CSS・JavaScriptへ直接記載しないでください。ブラウザーに配信されるコードは利用者が確認できるため、秘密情報を置く場所ではありません。

7-2. ログイン画面だけではデータを保護できない

画面上でログイン状態を確認するだけでは、データベースの保護にはなりません。Supabaseなどを使う場合は、テーブル・Storageのアクセス権限とRow Level Security（RLS）を適切に設定し、ユーザーごとにアクセス範囲を制限してください。

7-3. 入力フォーム・アップロード

フォームの入力値はブラウザー側だけでなく、サーバー側でも検証してください。ファイルを受け付ける場合は、ファイル形式・サイズ・保存先・閲覧権限を確認します。

7-4. 外部サービス・画像の利用

外部APIや画像URLを使う場合は、サービスの利用規約、公開範囲、利用権限を確認してください。APIキーを公開コードへ埋め込む必要がある設計は避けてください。

7-5. 保存・バックアップ

大きな変更を行う前に保存し、必要ならZIPを書き出してバックアップしてください。テンプレートの切り替えやコードの一括置換を行った後は、ページ内容が残っているか確認します。

7-6. エラーログとログローテーション

AevStudioの制作画面では、ブラウザー内で発生したJavaScriptエラーや未処理の非同期エラーを、原因確認用のログとして利用中の端末・ブラウザーに保存します。ログは端末ごとに保存され、別端末とは自動同期されません。

  • 保存期間：30日を過ぎたログは自動削除。
  • 保存件数：最大500件。上限を超えた場合は古いものから整理。
  • 保存容量：端末の保存容量が不足した場合は、件数を減らして保存を試みます。
  • 対象：JavaScriptエラー、未処理の非同期エラー、一部のリソース読み込みエラー。

この整理処理を「ログローテーション」といいます。ログの削除・整理はエラー記録だけを対象にし、メールアドレス、Supabase Authの登録ユーザー、パスワード、プロジェクトデータを削除する処理ではありません。ログには個人情報や秘密情報を含めないよう一部の文字列を伏せますが、エラー文に入力内容などが含まれる可能性もあるため、ログを共有する前に内容を確認してください。

この機能はブラウザー内のエラーログ管理です。GitHub PagesのサーバーログやSupabase側の監査ログを管理・削除する機能ではありません。

8. よくある問題と確認方法

画面が正しく動かない場合は、次の順番で確認してください。

8-1. プロジェクトが一覧に表示されない
  • 保存状態が完了になっているか確認します。
  • クラウド保存した場合は、保存時と同じアカウントでログインしているか確認します。
  • ゲスト保存の場合は、保存した端末・ブラウザーを使っているか確認します。
  • 通信が不安定な場合は、接続を確認してから再読み込みします。
8-2. 保存・クラウド同期が進まない

ネットワーク接続とログイン状態を確認し、保存状態が完了するまで待ちます。ログイン期限が切れている場合は再ログインしてください。保存完了前にページを閉じないでください。

8-3. プレビューが真っ白・更新されない
  • HTMLの閉じタグ、CSSの括弧、JavaScriptの構文エラーを確認します。
  • JavaScriptが存在しないIDの要素を取得していないか確認します。
  • 「更新」を押してプレビューを再読み込みします。
  • 閲覧モードとコード確認モードを切り替えて挙動を比較します。
  • エディタ内の制限とブラウザーのセキュリティ制限により、プレビュー内で一部の外部遷移が制限されることがあります。
8-4. コードを追加したら動かなくなった

追加したコードが必要とするHTML要素、ID、クラス、CSS、イベント処理が揃っているか確認します。同じIDを複数作らないでください。直前の変更を戻し、少しずつ追加して原因を切り分けます。

8-5. 画像が表示されない

画像URLが正しいか、URLが直接画像ファイルを指しているか、外部サイト側が埋め込み表示を許可しているか確認します。端末から追加した画像の場合は、追加処理の完了表示も確認してください。

8-6. 公開したサイトが編集画面と違う

ZIPの内容を最新状態で書き出したか、公開先へ正しいファイルを配置したか確認します。ブラウザーキャッシュの影響も考えられるため、再読み込みして確認してください。
